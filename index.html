AMCP Core Concepts

💬

Chat Agent

Conversational interface for multi-agent systems. Enables natural language interaction with intelligent agents, supporting context management, conversation history, and dynamic agent discovery.

Natural Language Context Aware Multi-turn
🎼

Orchestrator Agent

Intelligent coordinator for complex workflows. Manages agent lifecycle, routes messages, handles task decomposition, and orchestrates multi-step processes with LLM-powered decision making.

Workflow Management Task Routing LLM-Powered
🕸️

Mesh Agent

Distributed node in the agent mesh network. Provides autonomous capabilities, event-driven communication, service discovery, and seamless integration with the AMCP protocol for enterprise-scale deployments.

Distributed Event-Driven Autonomous

Protocol Support & Interoperability

🔌

MCP (Model Context Protocol)

Native support for Model Context Protocol enables seamless integration with AI models and tools. AMCP agents can act as MCP clients and servers, providing standardized interfaces for model interactions and resource access.

✓ MCP Client/Server ✓ Tool Integration ✓ Resource Management
🔄

A2A (Agent-to-Agent)

Direct agent-to-agent communication protocol for peer-to-peer interactions. Enables agents to discover, negotiate, and communicate with each other without central coordination, supporting decentralized multi-agent architectures.

✓ Peer-to-Peer ✓ Service Discovery ✓ Decentralized

Download AMCP

Build & Run

Compile and start the interactive CLI
