## Troubleshooting Guide

### If GitHub Actions Fails
1. Check GitHub Actions logs for errors
2. Verify HTML syntax is valid
3. Check CSS for syntax errors
4. Review file paths (especially video path)
5. Check for missing dependencies

### If Website Doesn't Update
1. Clear browser cache (Ctrl+Shift+Delete)
2. Wait 5-10 minutes for CDN to update
3. Check GitHub Pages settings
4. Verify main branch is selected for deployment
5. Check for build errors in Actions

### If Video Doesn't Load
1. Verify video file exists at `/promo/AMCP__The_Agent_Superhighway.mp4`
2. Check video file permissions
3. Verify video format is MP4
4. Test video path in browser
5. Check browser console for errors

### If Styling Looks Wrong
1. Clear browser cache
2. Check CSS file is loading
3. Verify no CSS conflicts
4. Test in different browser
5. Check responsive breakpoints
